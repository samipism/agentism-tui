# agentism documents

This folder holds the plan. The agent reads it through the `agentism`
command, not with grep.

- `INTENT.md` - why the product exists. It changes almost never.
- `ArchDecision.md` - the technical choices. It changes very rarely.
- `CODEBASE_MAP.md` - what the existing code does. Brownfield projects only.
- `tasks/` - the active tasks and their tickets.
- `versions/` - finished tasks, kept as a record.

Run `agentism status` to see where the project stands.
